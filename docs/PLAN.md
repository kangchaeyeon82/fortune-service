# 운세 서비스 계획서 (2차)

**밤하늘처럼 고요하고 빛나는 화면**에서 내 사주의 구성과 2026년·오늘의 운세를 쉬운 말로 풀어 주는 웹사이트.

## 2. 지금까지 한 것 (1차, 완료)

- 규칙 기반 풀이 엔진(`web/js/interpret.js`) — AI·비용 없음

## 4. 디자인 방향 (레퍼런스 사진 분석)

| 사진에서 공통으로 보이는 것 | 사이트에 옮기는 방법 |
|---|---|
| 거의 검은 밤하늘 배경 (#05060a 부근) | 다크 테마를 기본으로. 배경에 아주 옅은 별 점(작은 흰 점) 몇 개 |
| 금색 가는 선의 8방향 별 · 동심원 (나침반·별자리 도안) | 로고/첫 화면 상징, 사주팔자 원국표 장식, 구분선을 **1px 금색 가는 선**으로 |
| 보라·남색 빛, 은하수 곡선 | 강조색을 보라(#8b7cf6 계열)로, 카드 테두리·선택 탭에 은은한 보라 빛(glow) |
| 흰 별빛 반짝임(4~8갈래 빛줄기) | 점수·핵심 숫자 옆 작은 별 아이콘, 로딩 중 반짝이는 별 애니메이션 |
| 무지갯빛(홀로그램) 빛 번짐 | 점수 카드 등 **딱 한두 곳에만** 옅게 사용 (많이 쓰면 촌스러움) |
| 마법진 같은 원형 도안 | 오행 분포를 **원형(오각형) 도표**로 — 목·화·토·금·수가 원 위에 놓이는 형태 |

**지킬 것 (밤티 금지)**
- 색은 검정 · 금 · 보라 · 흰색 4가지 위주. 오행 5색은 그래프 안에서만.
- 빛 효과는 은은하게(투명도 낮게), 움직임은 느리고 적게. 글자는 또렷하게.
- 이모지 대신 가는 선 아이콘. 글꼴은 지금처럼 Pretendard, 제목만 얇은 굵기.
- 휴대폰 화면 기준으로 먼저 설계.

## 5. 풀이 방식 (saju-explain.md 예시 반영)

예시의 구성: **표로 한눈에 → 상태 한 단어(적정/과다/결핍) → 💡 종합 해석 문단**.
이 틀을 각 항목에 똑같이 적용한다.

### 탭 1 · 내 사주
| 항목 | 지금 | 2차에서 바꿀 점 | 데이터 |
|---|---|---|---|
| 기본 정보 | 이름·생년월일 한 줄 | 양력/음력 변환, 출생지, **진태양시(보정 시각)**, 절기 기준월 표 | 포스텔러 제공 |
| 사주 원국표 | 8글자 카드 | 한 표에 **십성 · 천간 · 지지 · 지장간 · 12운성 · 신살**을 함께 | 포스텔러 제공 |
| 오행 분석 | 막대 그래프 | 글자·개수·비율 + **상태(적정/과다/결핍)**, 용신 표시 | 제공 + 계산 |
| 십성 분포 | 그래프 | 자리별 십성 표 + **5그룹(비겁·식상·재성·관성·인성) 개수와 키워드** | 제공 |
| 대운 | 목록 | 나이 · 간지 · 천간/지지 오행 · **해당 연도 범위** 표, 지금 대운 강조 | 제공 |
| 신살 · 귀인 | 칩 목록 | 위치·의미 표 + **💡 신살 종합 해석** 문단 | 제공 |
| 12운성 (신규) | 없음 | 자리별 운성 + 에너지 단어(제왕=최강 등) + **일주 운성 해석**, 초년→말년 흐름 | 제공 |
| 지장간 (신규) | 없음 | 여기·중기·정기 표 + **숨은 기운 보완** 해석 (겉에 없는 오행이 속에 있는지) | 제공 |
| 형충회합 (신규) | 없음 | 천간합 · 육합 · 충 · 원진 · 파/해 목록과 한 줄 의미 | **직접 계산** |
| 적성 · 직업 (신규) | 없음 | 십성·신살 조합으로 추천 직업군 3~4개 + 커리어 조언 | **규칙으로 작성** |

### 탭 2 · 2026년 운세 (병오년)
- **운세 키워드**: 총운 한 줄 + 분야별 별점(★5개)과 한 줄 설명
- 분야별 지수 · 월별 흐름 · 주의할 점 · 개운법 (지금 있는 것 유지)
- **💡 2026년 조언** 문단: 올해 기운이 내 사주에 무엇을 채우는지/넘치게 하는지, 좋은 시기(월) 짚기

### 탭 3 · 오늘의 운세
- 지금 구조 유지, 문장 톤만 예시처럼 "키워드 + 조언 문단"으로 통일

### 문장 원칙
- 어려운 용어는 괄호로 한자·뜻을 붙이고 바로 쉬운 말로 풀기 (예: "편인(偏印) — 남다른 관점과 직관")
- 단정·공포 표현 금지. 나쁜 기운도 "이렇게 쓰면 좋다"로 마무리
- 예시는 참고만 하고 문장은 규칙으로 새로 만든다 (같은 사주면 같은 풀이)

## 6. 작업 순서
1. [ ] 디자인 토큰 교체 — 밤하늘 배경, 금·보라 강조색, 가는 선, 별 장식 (`web/css/style.css`)
2. [x] 입력 폼 — 포스텔러 방식(숫자 직접 입력, 도시 직접 입력)
2-1. [ ] 첫 화면 — 8방향 별 도안 이미지(구글 Flow 생성)
3. [ ] 내 사주 탭 — 원국표 확장(지장간·12운성·신살), 오행 상태·원형 도표, 십성 5그룹
4. [ ] 신규 항목 — 12운성 · 지장간 · 형충회합(계산) · 적성/직업(규칙)
5. [ ] 해석 문단 — 각 항목 끝에 💡 종합 해석, 2026년 키워드·별점·조언
6. [ ] 휴대폰·다크 화면 점검, 여러 생년월일로 문장 어색한 곳 확인
7. [ ] GitHub Pages 배포 → 발표

## 7. 기술 · 주의사항
- 화면: HTML/CSS/JS 그대로 (GitHub Pages, 서버 불필요). 장식 이미지는 구글 Flow(AI 이미지 생성)로 만들어 `web/img/`에 넣음
- 레퍼런스 사진은 분위기 참고용 — 사이트에 그대로 쓰지 않고, 비슷한 느낌의 이미지를 새로 생성해 사용
- 포스텔러 API는 공개 문서가 없는 내부 API → 바뀌면 동작이 멈출 수 있음
- 입력 정보는 저장하지 않음. 운세는 "재미/참고용" 문구 표시
