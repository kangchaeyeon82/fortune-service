# 사주 풀이 (fortune-service)

만세력 데이터를 바탕으로 내 사주가 어떻게 이루어져 있는지 표와 그래프로 보여 주고, 2026년 운세와 오늘의 운세를 쉬운 말로 풀어 주는 웹사이트입니다. (수업 프로젝트)

**바로 사용하기 → https://kangchaeyeon82.github.io/fortune-service/**

설치 없이 브라우저에서 바로 쓸 수 있고, 휴대폰 화면도 지원합니다.

## 사용 방법

1. 첫 화면에서 정보를 입력합니다. (포스텔러 만세력과 같은 방식)

   | 항목 | 입력 방법 |
   |---|---|
   | 이름 | 최대 12글자 |
   | 성별 | 여자 / 남자 |
   | 생년월일 | 양력 · 음력 · 음력(윤달)을 고르고 숫자 8자리 입력 — `19900101` → `1990/01/01` |
   | 태어난 시각 | 숫자 4자리 입력 — `1430` → `14:30`. 모르면 '시간 모름' |
   | 도시 | 직접 입력하면 아래에 후보가 뜸. 고르지 않아도 첫 번째 후보로 정해짐 (전 세계 도시 검색) |

2. **사주 풀이 보기**를 누르면 마법진이 도는 동안 풀이를 불러와 세 개의 탭으로 보여 줍니다.
3. 표의 글자, 그래프 막대, 항목을 누르면 아래에서 해석 창이 올라옵니다.
4. 입력 없이 둘러보려면 **예시로 둘러보기**를 누르세요.

## 무엇을 볼 수 있나요

모든 항목은 **표로 한눈에 → 상태 한 단어(적정·발달·과다·결핍) → ✦ 종합 해석 문단** 순서로 보여 줍니다.

### 내 사주

| 항목 | 내용 |
|---|---|
| 기본 정보 | 양력·음력, 태어난 곳, 진태양시(지역 보정 시각), 띠, 절기 기준 월 |
| 사주 원국표 | 시·일·월·년 기둥의 십성 · 천간 · 지지 · 지장간 · 12운성 · 신살 + 원국 요약 |
| 오행 분석 | 오행별 해당 글자 · 개수 · 비율 · 상태, 오행의 힘 그래프, 기둥별 오행 그래프, 일간 · 신강신약 · 용신 |
| 십성 분포 | 자리별 십성, 비겁·식상·재성·관성·인성 개수와 키워드, 십성별 비중 그래프 |
| 대운 | 대운 방향(순행·역행), 시작 나이, 10년 단위 대운 표(지금 대운 표시) |
| 신살 분석 | 신살·귀인의 위치와 의미 + 신살 종합 해석 |
| 12운성 | 기둥별 12운성과 에너지 + 초년에서 말년까지의 흐름 |
| 지장간 | 여기·중기·정기와 십성 + 겉에 없는 기운이 속에 숨어 있는지 |
| 형충회합 | 천간합 · 육합 · 삼합 · 방합 · 충 · 형 · 파 · 해 · 원진 · 공망 |
| 적성 · 직업 | 추천 직업군과 이유 + 커리어 조언 |

### 2026년 운세

운세 키워드(총운 한 줄, 분야별 ★ 별점) · 2026년 조언 · 올해 운세 지수 · 분야별 지수(연애·재물·직장학업·대인관계·건강) · 월별 흐름 · 주의할 점 · 개운법

### 오늘의 운세

오늘의 점수 · 오늘의 개운법(행운의 색·숫자·방향·아이템 등) · 시간대별 흐름 · 오늘의 기운과 나

## 디자인

레퍼런스 사진(`docs/references/screenshots/`)의 분위기를 옮겼습니다.

- **색:** 검은 배경에 흰색을 메인으로 쓰고, 카드는 뒤가 흐리게 비치는 반투명 유리처럼 만들었습니다.
- **배경:** 작은 별과 4·8갈래 십자 별빛이 은은하게 반짝이고, 라벤더빛 은하수 리본과 무지갯빛 곡선이 천천히 흐릅니다.
- **첫 화면:** 위에서 비추는 별빛 아래 하얀 마법진이 돌고, 빛기둥과 반짝이 가루가 피어오릅니다.
- **로딩:** 풀이를 불러오는 동안 마법진이 빠르게 돕니다.
- **동작 줄이기:** 기기에서 '동작 줄이기'를 켜면 회전과 반짝임이 멈춥니다.

## 어떻게 동작하나요

1. **만세력 데이터:** [포스텔러 만세력](https://pro.forceteller.com)에서 가져옵니다. 브라우저가 직접 호출하므로 서버가 필요 없습니다.
   - 가져오는 것: 사주명식(지장간·12운성 포함), 오행·십성, 신강신약, 용신, 대운·연운·월운, 신살, 글자 사이의 합·충 관계
2. **직접 계산하는 값:** 데이터에 없어서 직접 계산합니다. 포스텔러 값과 대조해 모두 일치하는 것을 확인했습니다.
   - 오늘의 일진과 시간대별 간지
   - 첫 대운 전 어린이의 올해 간지
   - 대운 방향(순행·역행)
3. **풀이:** AI 없이, 명리학의 일반적인 해석을 규칙으로 옮겨 문장과 점수를 만듭니다. 같은 사주면 언제나 같은 풀이가 나옵니다.
   - 올해·오늘의 기운이 나에게 필요한 기운(용신)이면 점수가 오르고, 이미 넘치는 기운이면 내려갑니다.
   - 연애운은 이성 인연을 뜻하는 기운과 도화살, 배우자 자리(일지)와의 합·충을 봅니다.
   - 학업운은 인성·관성 기운과 문창·학당귀인 같은 공부 별을 봅니다.
   - 올해 지지와 내 사주가 부딪히는지(충), 삼재인지도 계산합니다.
   - 신살 종합 해석과 적성·직업은 실제로 가진 신살과 십성으로만 문장을 만듭니다. (예: 괴강살이 있는 사람에게만 "남에게 기대지 않는 카리스마")

## 연결된 외부 도구

| 도구 | 어디에 쓰나 | 키·비용 | 사용하는 곳 |
|---|---|---|---|
| **포스텔러 만세력 API** (`api.forceteller.com`) | 사주 데이터, 태어난 곳(도시) 검색, 날짜 검증 | 키 없음 · 무료 | `web/js/api.js`, `server/forceteller.py`, `crawler/` |
| **Firecrawl** (`api.firecrawl.dev`) | 포스텔러 첫 화면을 수집하는 데만 사용. 웹사이트는 사용하지 않음 | `FIRECRAWL_API_KEY` 필요 (`.env`) | `crawler/forceteller_crawl.py` |
| **GitHub Pages + GitHub Actions** | `main`에 push하면 `web` 폴더를 자동으로 배포 | 무료 (공개 저장소) | `.github/workflows/pages.yml` |
| **Google Flow (나노 바나나 2.1)** | 마법진 이미지 생성 (`web/img/magic-circle.webp`) | 구글 계정 | 이미지를 만들 때만 사용, 사이트 동작과는 무관 |
| **jsDelivr CDN · Pretendard 글꼴** | 화면 글꼴 | 키 없음 · 무료 | `web/index.html` |
| **FastAPI · Uvicorn · httpx** (파이썬 라이브러리) | 내 컴퓨터에서 서버로 실행할 때만 사용 | 무료 | `server/main.py`, `requirements.txt` |

- AI API(Claude, ChatGPT 등)는 쓰지 않습니다.
- API 키는 `.env` 파일에만 넣고, 이 파일은 GitHub에 올리지 않습니다(`.gitignore`). 형식은 `.env.example`을 참고하세요.

```
│   ├── css/style.css

│   │   ├── api.js              #   포스텔러 호출 · 도시 검색 · 날짜 검증 · 일진 계산
│   │   ├── interpret.js        #   풀이 엔진: 점수 · 올해 · 오늘 · 개운법 · 해석 창 문장
│   │   ├── interpret-detail.js #   표 + 종합 해석 (원국표 · 오행 · 십성 · 대운 · 신살 · 12운성 · 지장간 · 형충회합 · 적성)
│   │   └── app.js              #   입력 폼 · 탭 3개 · 해석 창 · 로딩 화면

│   ├── main.py                 #   FastAPI 서버

│   └── references/
│       ├── README.md           #   레퍼런스 목록
│       ├── forceteller-api.md  #   포스텔러 API 정리
│       ├── data-schema.md      #   데이터 구조

├── .env.example
├── requirements.txt
└── README.md
```

- 풀이 방식 예시(`docs/references/saju-explain.md`)는 개인 정보가 있어 내 컴퓨터에만 두고 GitHub에는 올리지 않습니다.

## 내 컴퓨터에서 실행하기 (선택)

웹사이트만 쓸 거라면 필요 없습니다. 코드를 고쳐 보며 확인하고 싶을 때 사용하세요.

```
pip install -r requirements.txt
python -m uvicorn server.main:app
```

- 화면: http://127.0.0.1:8000
- API 문서: http://127.0.0.1:8000/docs (`/api/fortune`, `/api/cities` 등 — 화면과 같은 데이터를 API로 제공)
- 코드를 고친 뒤에는 서버를 껐다 다시 켜야 반영됩니다.

데이터만 파일로 받고 싶다면 수집 스크립트를 쓸 수 있습니다. Firecrawl 키가 필요하면 `.env.example`을 참고해 `.env`를 만드세요.

```
python crawler/forceteller_crawl.py --birthday 1990-01-01 --time 12:00 --gender F --out data/raw/test.json
```

## 배포

`main` 브랜치에 push하면 GitHub Actions가 `web` 폴더를 GitHub Pages에 자동으로 배포합니다. 보통 30초 안에 끝납니다.

## 알아 둘 점

- 사주 데이터는 포스텔러 만세력의 공개되지 않은 내부 API를 사용합니다. 포스텔러가 API를 바꾸거나 외부 요청을 막으면 사이트가 동작하지 않을 수 있습니다.
- 입력한 정보는 저장하지 않고, 사주 계산을 위해 포스텔러에만 전달됩니다.
- 운세 풀이는 재미와 참고용입니다.
